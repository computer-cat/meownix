# Meow~~mix~~nix!

This repository is for my personal Arch bootc image, heavily based on [Amethyris](https://github.com/Smujb/amethyris) 

Meownix currently includes a full usable Niri (will likely switch to umbriel once that project matures) + Noctalia v5 desktop including noctalia-greeter as well as a set of packages that I use day to day. Many things included are specific to my workflow however the base image is kept relatively lean. Software not baked in is intended to be installed with flatpak, brew, or distrobox.

No support will be provided as this project is exclusively intended for personal use, however feel free to try it if you'd like!

If you'd like to build your own image, I suggest using this [template.](https://github.com/Smujb/mkosi-arch-bootc)
